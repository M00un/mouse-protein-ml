# Data

This project uses the UCI Mice Protein Expression dataset.

The raw dataset is not stored directly in this repository. It is
downloaded programmatically from the UCI Machine Learning Repository.

Dataset citation:

Higuera, C., Gardiner, K., & Cios, K. (2015).
Mice Protein Expression. UCI Machine Learning Repository.
https://doi.org/10.24432/C50S3Z
